# 灵魂植物性格测试 🌿

一个基于华为云码道（CodeArts）代码智能体开发的趣味性格测试 H5。回答 12 道情景选择题，系统将匹配你的专属灵魂植物——含 15 种常规植物和 1 种隐藏款，每一株都有独特的花语与性格画像。

## 🪴 项目特点

- **完整的答题流程**：封面页 → 答题页（逐题 + 进度条 + 返回修改） → 结果页。
- **16 种植物结果**：向日葵、仙人掌、含羞草、竹子、蒲公英、睡莲、银杏、多肉、薰衣草、玫瑰、捕蝇草、柳树、松树、蘑菇、枫树，以及隐藏款 **昙花**（触发概率约 1%）。
- **细节拉满**：每种植物配有中文名、趣味拉丁名、一句艺术短句、花语、性格描述、专属“光合作用方式”与“适合养在哪儿”。
- **隐藏款惊喜**：昙花触发条件严苛（结合答题倾向 + 随机概率），增加传播惊喜感。
- **移动端优先**：适配手机屏幕，圆角柔和设计，大地色系治愈风格。
- **轻量无依赖**：纯原生 HTML + CSS + JavaScript，单文件即开即用。

## 🛠 技术栈

- HTML5 / CSS3 / JavaScript（ES6）
- 开发工具：华为云码道（CodeArts）代码智能体（GLM-5.1 / DeepSeek-V3.2）
- 图标库：Font Awesome 6（CDN 引入）

## 🧠 AI 开发说明

本项目由 **华为云码道 AI 智能体** 根据自然语言 Prompt 一次性生成完整框架，人工在此基础上进行细微样式调优。开发过程体现了“通过精细 Prompt 工程驾驭 AI 生成生产力级代码”的思路，符合华为云“AI 来开挂”高校编程创意赛的主题。
